# 📚 Приключения абитуриента

**Приключения абитуриента** — это визуальная новелла о поступлении в РТУ МИРЭА.  
Проект создан для абитуриентов, чтобы в интерактивной форме познакомить их с университетом, учебным процессом и студенческой жизнью.

---

## 🛠️ MVP (Minimum Viable Product)

### Основной функционал:
- ✅ Линейный сюжет с выбором реплик.
- ✅ Основные локации:
  - Главный вход РТУ МИРЭА
  - Аудитории и лектории 
  - Кмпьютерный клуб
  - Столовая
  - Тренажерный зал
- ✅ Ключевые персонажи:
  - Абитуриент
  - Студенты
  - Преподаватели
  - Сотрудники вуза
- ✅ Диалоги с базовой информацией об университете.
- ✅ Возможность перехода между локациями.
- ✅ Базовое визуальное оформление:
  - Фоновые изображения локаций
  - Спрайты персонажей
- ✅ Сохранение и загрузка прогресса.
- ✅ Поддержка русского языка.
- ✅ Звуковое сопровождение

---

## 📅 Цель MVP

- Быстрая проверка идеи интерактивной экскурсии.
- Получение обратной связи от пользователей.
- Определение направлений для дальнейшего расширения (новые ветки сюжета, мини-игры, анимации, английская версия).

---

## ✨ Технологии

- Движок: **Ren'Py** (или аналогичный для визуальных новелл)
- Языки: **Python** (Ren'Py-скрипты), **JSON** (для хранения данных)
